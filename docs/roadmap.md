# Focus

Help AI understand how a game fits together before it plans architecture or builds a new system.

The stable product boundary is a compact map: one setup command, one agent tool, automatic source refresh, and honest coverage. Engine adapters provide different facts through that shared interface.

Current adapters: Unity, Unreal source/config and asset locations, HTML5/Phaser, and exact Cocos UUID links. Each adapter exposes the project relationships available in its source formats.

Next planned adapter: Godot. Target signals are project.godot settings, .tscn/.tres external-resource relationships and GDScript declarations/import-like references. This adapter is the next planned extension.

Prioritize real navigation failures and native-client activation over dashboards, autonomous edits, conversation memory, broad tool inventories, or savings claims without task-quality measurements.
